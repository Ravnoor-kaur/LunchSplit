# Reflection – Assignment 1

## Start

I will start writing unit tests before implementing new functionality whenever possible. 
Using Test-Driven Development (TDD) helped me understand the expected behavior of the 
LunchSplit components before writing the production code. I will also continue using 
small, meaningful Git commits so that my development progress is easier to track.

## Stop

I will stop relying on manual testing alone to determine whether the application works 
correctly. The MSTest cases showed me that individual conditions and edge cases need to 
be tested separately. I will also stop making large changes without running the test 
suite afterward.

## Continue

I will continue using the Arrange-Act-Assert (AAA) structure for my unit tests because 
it makes each test easier to understand. I will also continue using meaningful test 
names that describe the expected behavior. For future assignments, I will continue 
building on the LunchSplit codebase while maintaining the existing tests and improving 
test coverage.
